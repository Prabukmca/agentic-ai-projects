# PII and Data Sharing Safety (Curated)

Source: https://www.cisa.gov/
Last-checked: 2026-09-30
Use: Privacy-safe user guidance and logging policy alignment.

Key points:
- Never share sensitive personal details on unsolicited calls/messages.
- Use official channels for document upload and identity verification.
- Minimize exposure of account IDs and personal identifiers.
- If personal data has already been exposed, escalate to bank fraud support quickly.
