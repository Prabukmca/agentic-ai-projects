# KYC Update Overview (Curated)

Source: https://www.rbi.org.in/
Last-checked: 2026-09-30
Use: Non-transactional process guidance.

Key points:
- KYC updates may require identity and address proof per bank requirements.
- Updates can be done via branch, and in some cases through secure digital workflows.
- Customers should submit documents only via official channels.
- If a user asks for account-specific KYC status, escalate to authenticated bank support.
