# Dormant Account Reactivation Basics (Curated)

Source: https://www.rbi.org.in/
Last-checked: 2026-09-30
Use: Account-status process guidance.

Key points:
- Dormant account activation generally requires customer verification.
- Banks may ask for identity confirmation and account holder request forms.
- Channel availability differs by bank; branch support may be required.
- Account-specific status checks must be handled by authenticated support.
