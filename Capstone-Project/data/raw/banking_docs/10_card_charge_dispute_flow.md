# Card Charge Dispute Flow (Curated)

Source: https://www.mastercard.co.in/
Last-checked: 2026-09-30
Use: General dispute process guidance.

Key points:
- Customers should report unfamiliar card charges quickly.
- Banks usually request transaction date, merchant name, and reason for dispute.
- Supporting evidence improves investigation outcomes.
- Agent should avoid final liability claims and route unresolved outcomes to escalation channels.
