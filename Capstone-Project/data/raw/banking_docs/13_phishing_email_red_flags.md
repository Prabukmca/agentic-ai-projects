# Phishing Email and Message Red Flags (Curated)

Source: https://consumer.ftc.gov/
Last-checked: 2026-09-30
Use: Fraud detection guidance for ambiguous support chats.

Key points:
- Urgent language, reward bait, and credential requests are common scam indicators.
- Mismatched sender domains and suspicious links are warning signs.
- Users should avoid clicking unknown links and verify directly with official support.
- Agent should classify these as high-risk and recommend escalation.
