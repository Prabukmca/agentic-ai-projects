# ATM Usage and Safety Policy (Curated)

Source: https://www.rbi.org.in/
Last-checked: 2026-09-30
Use: ATM transaction limits and safe usage guidance.

Key points:
- ATM cash withdrawal limits vary by card type, account type, bank, and daily transaction rules.
- Cardholders should use secure ATMs and avoid shared or suspicious machines.
- Customers should shield their PIN while entering it and never share OTPs or card details.
- If a card is retained or an ATM is suspicious, customers should contact the bank immediately.
- Cash withdrawal counts and daily caps may differ for ATM cash, POS, and e-commerce transactions.
- Some banks apply additional limits for international ATM usage or premium card categories.
- If a transaction is not authorized, customers should block the card and report it to the bank promptly.
- Regularly checking transaction alerts helps identify unauthorized ATM usage early.
