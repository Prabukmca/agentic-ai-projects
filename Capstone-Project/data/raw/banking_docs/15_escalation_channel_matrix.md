# Escalation Channel Matrix (Curated)

Source: https://www.rbi.org.in/ ; https://cms.rbi.org.in/
Last-checked: 2026-09-30
Use: Standardized escalation guidance wording.

Key points:
- Level 1: Bank app/website support and official hotline.
- Level 2: Branch escalation with complaint reference.
- Level 3: External grievance route through regulator complaint channels.
- Agent should provide escalation level based on risk (fraud/legal/ambiguous cases).
