# Debit/Credit Card Blocking Process (Curated)

Source: https://www.visa.co.in/
Last-checked: 2026-09-30
Use: Lost-card response guidance.

Key points:
- Customers should block or hotlist a lost card immediately via app, web banking, or hotline.
- After blocking, customers should request a replacement card.
- Customers should review recent transactions for suspicious activity.
- High-risk activity should be escalated to fraud support.
