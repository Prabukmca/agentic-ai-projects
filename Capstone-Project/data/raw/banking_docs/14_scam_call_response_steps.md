# Scam Call Response Steps (Curated)

Source: https://www.fcc.gov/
Last-checked: 2026-09-30
Use: Response checklist for suspected social-engineering calls.

Key points:
- End suspicious calls immediately and do not provide verification codes.
- Call back the bank using published numbers from official website/card back.
- Monitor account and card activity for unusual transactions.
- Raise a fraud complaint promptly if compromise is suspected.
