# Grievance Redressal and Ombudsman Route (Curated)

Source: https://cms.rbi.org.in/
Last-checked: 2026-09-30
Use: Escalation path when complaints are unresolved.

Key points:
- Customers should first file a complaint with their bank and keep the complaint number.
- If unresolved within the expected period, customers can escalate through RBI's grievance channels.
- Responses should avoid legal advice and instead provide official escalation pathways.
- Agent should direct users to official portals and customer care channels.
